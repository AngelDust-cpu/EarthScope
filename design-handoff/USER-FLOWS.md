# Сценарии пользователя

Во всех формах запуск явный. Изменение параметров до запуска считается черновиком. При ошибках показать действие восстановления. Успешный результат сопровождается координатами, периодом, единицами и происхождением.

1. **Первое знакомство.** Открыть EarthScope → увидеть «Одна точка», карту и предзаполненный Бишкек → кликнуть в другой точке или оставить пресет → выбрать показатель и годы → провести анализ → увидеть годовой график и научное резюме. Для пошаговой помощи открыть «Детектив».
2. **Одна точка.** Выбрать координаты с карты/ввода/пресета → температура или осадки → первый и последний год → запуск → прочитать наклон, интервал, p и среднее → открыть таблицу и переключить полные годы/пропуски → выгрузить. При редактировании проверить пометку прежнего результата.
3. **Сравнение двух точек.** Открыть A/B → выбрать A, установить её координаты → выбрать B, установить её координаты → общий показатель и период → запуск → сравнить графики наложением или рядом → при необходимости выбрать аномалии и общие базовые годы → прочитать описательную разность наклонов и таблицу → выгрузить.
4. **Аномалии.** Выбрать место, показатель и годы графика → 1991–2020 или ручная база → запуск → прочитать норму, полноту, график с нулём и таблицу → CSV/PDF. При неполной базе объяснить, почему отклонений нет.
5. **Сезонность.** Выбрать место, показатель, годы → сезон, месяц или все сезоны → запуск → графики, таблицы и оценки по периодам → CSV/PDF. Зима относится к году января.
6. **Экстремумы.** Выбрать пороговые дни → одно из трёх событий → порог и годы → выбрать точку и при необходимости включить B → запуск → выбрать год столбцом или селектором → прочитать точное число, покрытие и статистику → выгрузить. При A/B сравнение остаётся описательным.
7. **Волны жары.** Переключить подрежим → место, годы, порог и минимум суток → запуск → три графика и общая сводка → выбрать год → увидеть эпизоды по датам → скачать годовой CSV, список эпизодов или PDF.
8. **Карта трендов.** Открыть раздел → дождаться автоотображения → температура/осадки → тренд или BY → плавный слой или исходная сетка → панорамировать/приблизить → выбрать исходный узел кликом или по координатам → прочитать годовую таблицу, p/q и интервал → PDF ячейки.
9. **Климатический профиль.** Точка, годы, база → при необходимости открыть пороги → составить профиль → прочитать метрики, сводку и ошибки отдельных секций → раскрыть нужные графики, таблицы и ограничения → единый CSV/PDF. Волны жары рассчитываются в самостоятельном режиме.
10. **Детектив.** Выбрать одну из восьми карточек → карта и координаты (две точки для A/B) → годы и специфические параметры → запуск → текстовый ответ, графики, источник и доступные выгрузки. Можно вернуться с сохранением ввода, повторить, открыть подходящий уже рассчитанный ответ или начать заново. Запоздалый ответ не восстанавливает сброшенное исследование.
11. **Экспорт.** Выполнить анализ или открыть мировую ячейку → выбрать доступный формат → дождаться подготовки → сохранить. При отказе показать ошибку и дать повтор. CSV отдельных анализов представляет текущие рассчитанные данные. PDF и единый профильный CSV повторяют запрос с зафиксированными параметрами. В A/B PDF отражает исходный анализ, а не клиентский вид графика или изменённую базу. PNG доступен там, где есть панель Plotly.
